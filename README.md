# CS 305 Module Eight Journal

## Artemis Financial Practices for Secure Software Report

### Briefly summarize your client, Artemis Financial, and its software requirements. Who was the client? What issue did the company want you to address?

Artemis Financial was the client for this project. The company provides financial services and wanted to improve the security of its software application. The main goal was to identify security vulnerabilities and make sure sensitive information was protected. I was responsible for reviewing the application, finding possible security risks, and making changes to improve the security of the software.

### What did you do well when you found your client’s software security vulnerabilities? Why is it important to code securely? What value does software security add to a company’s overall well-being?

I did well identifying vulnerabilities and determining ways to improve the security of the application. I reviewed the code and used security testing tools to find possible weaknesses. Secure coding is important because it helps protect sensitive customer and company information from unauthorized access or attacks. Strong software security also helps a company maintain customer trust, reduce security risks, and avoid financial or reputational damage.

### Which part of the vulnerability assessment was challenging or helpful to you?

One of the most challenging parts was reviewing the dependency-check results and determining which vulnerabilities were important to the application. At the same time, this was helpful because I learned how automated security tools can identify vulnerabilities in software dependencies. It also showed me that developers need to review security reports carefully instead of only relying on the tool's results.

### How did you increase layers of security? In the future, what would you use to assess vulnerabilities and decide which mitigation techniques to use?

I increased the layers of security by implementing secure communication using HTTPS, creating a self-signed certificate, and using the SHA-256 hashing algorithm to verify data integrity. I also used dependency checking to identify known vulnerabilities. In the future, I would use vulnerability scanning tools, secure coding standards, dependency checks, and manual code reviews to identify security risks and determine the best mitigation techniques.

### How did you make certain the code and software application were functional and secure? After refactoring the code, how did you check to see whether you introduced new vulnerabilities?

I tested the application after making security changes to make sure it still worked correctly. I ran the application and verified that the secure HTTPS connection worked as expected. I also ran the dependency-check tool again after refactoring the code. This allowed me to compare the results and check whether the changes introduced any new vulnerabilities or security problems.

### What resources, tools, or coding practices did you use that might be helpful in future assignments or tasks?

Some of the tools and practices I found helpful were Eclipse, Java, Maven, Spring Boot, OWASP Dependency-Check, SHA-256 hashing, HTTPS, certificates, and secure coding practices. I also learned the importance of testing software after making changes and reviewing dependencies for known vulnerabilities. These skills and tools will be useful in future software development and security projects.

### What might you show future employers from this assignment?

I would show future employers my Artemis Financial Practices for Secure Software Report and the secure application I worked on. These artifacts demonstrate my ability to identify software vulnerabilities, implement secure communication, use hashing to protect data integrity, perform dependency checks, and test an application after making security improvements. This project shows that I understand the importance of including security throughout the software development process.

## Reflection

Overall, this project helped me better understand how software development and security work together. I learned that developers should consider security throughout the entire development process instead of waiting until the application is finished. The skills I gained from this project will help me develop applications that are both functional and secure in future courses and professional projects.
